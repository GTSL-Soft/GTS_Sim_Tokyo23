【超巨大娘 災害進行観測速報（東京23区プロトタイプ）スタンドアロン版】

■ 起動方法
このフォルダ内にある「index.html」を、お使いのブラウザ（Google Chrome, Microsoft Edge, Firefox 等）で
ダブルクリック（またはブラウザ画面にドラッグ＆ドロップ）して開いてください。
ローカルWebサーバー（node / python 等）を起動することなく、単体でそのまま動作します。

■ フォルダ構成
- index.html   : システム本体（ブラウザで開くファイル）
- style.css    : 画面デザイン・スタイルシート
- bundle.js    : シミュレーター本体・統計データ（東京23区）統合スクリプト
- audio/       : BGMおよび必殺技効果音（bgm.mp3, Special1〜3.wav）
- leaflet/     : 地図レンダリングライブラリ用アセット

■ 動作要件
- 一般的な最新のモダンブラウザ（Google Chrome, Microsoft Edge, Firefox, Safari 等）
- 地図タイルの表示にはインターネット接続環境が必要です（国土地理院タイルを読み込みます）。


■遊び方
巨大娘の名前、大きさ、必殺技名、必殺技効果音を設定したら、地図上の東京23区内をクリックして巨大娘出現位置と到達位置を設定し、進行シミュレーション開始をクリック。あとは巨大娘の移動を眺めながら増えていく被害に思いを寄せてください。
必殺技ゲージがたまったら必殺技ボタンを押すとより広い範囲を破壊できます。
そんだけ。
